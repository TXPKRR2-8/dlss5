# 游戏超分&帧生成工具合集
> 支持A卡/N卡 | 多倍帧生成 | DLSS 5 神经渲染叠加 | 一键安装免手动替换文件


## 一、OptiScaler-DLSSNR 一键安装器
### 前置说明：先确认游戏兼容性
工具必须搭配**支持超分辨率上采样**的游戏使用，FSR / XeSS / DLSS 三者支持其一即可
- 查看方法：游戏设置 → 画面选项 → 找到「上采样方式」
- 主流3A大作、《燕云十六声》《黑神话：悟空》等多数网游均支持

### 安装步骤（全程一键，无需手动改文件）
1. 双击打开安装器（无需安装到系统，自动生成临时文件夹）
2. 首页点「安装」，选择游戏目录：
   - 普通游戏：直接选游戏 `.exe` 所在的根目录
   - 虚幻引擎游戏：exe不在根目录，需定位到 `游戏文件夹/Binaries/Win64/游戏名Win64Shipping` 文件夹（文件夹同时包含引擎目录+游戏名目录，基本可判定为虚幻引擎）
3. 粘贴目录后工具会自动识别，API默认选DX12即可（个别游戏异常再切换DX11或Winmm）
4. 点「安装」，完成后会自动在目录生成注入文件
   - 启动游戏：从安装器点「启动」，或直接运行游戏原exe均可

### 使用方法
1. 进入游戏后，**按 `Insert` 键呼出/关闭插件主面板**
   - 若按Insert面板闪一下就消失，尝试 `Alt + Insert` 兼容特殊键盘布局
   - 首次启动会提示：先去游戏设置里把上采样改成 DLSS / FSR 2 / XeSS，重启游戏后再使用插件
2. 面板核心功能按需调整：
   - **超分设置**：选择目标超分方案，点「应用超分设置」
   - **帧生成**：可选2/4/6倍档，也可开启实验性12倍；鼠标悬停选项有功能说明，按需选择
   - **DLSS 5 神经渲染（NR）**：开启后支持1-10层效果叠加，2层及以上可自定义每层权重（强度、结构、色调、高光保护等）
3. 全部调整完成后点「保存设置」，重启游戏生效
4. 按 `Page Up` 键，可在左上角显示/关闭实时帧率、原始帧率和延迟数据

### 卸载还原
打开安装器 → 进入「管理」页面 → 选中已安装的游戏 → 点「卸载并恢复」即可还原原始文件

## 二、DLSS 5 Swapper 全功能集成版
### 2.1 工具介绍
DLSS 5 Swapper 是开源免费的一站式 DLSS 5 部署工具，集成了 RenoDX、OptiScaler、DLSS-Feeder 等多种方案，既支持原生 DLSS 游戏，也能给无原生超分的老游戏/模拟器强制注入 DLSS 5，自带自动备份、游戏内调节面板、社区兼容性查询等功能。

### 2.2 版本说明（2.2.7 vs 2.2.9）
#### v2.2.7 经典稳定版
- 新增按显卡型号筛选社区报告功能，同款硬件的兼容性参考更精准
- 新增 DirectDraw 支持（集成 dgVoodoo），可适配更多老模拟器和早期游戏
- 修复《掠食》《泰坦陨落2》等独立渲染DLL游戏的识别问题
- 优化安装流程，修复安装提示过早弹出的问题，明确卸载仅还原原始文件、不修改游戏目录
- 更新 DLSS5-Feeder、RenoDX 等核心组件，提升整体稳定性

#### v2.2.9 最新版
- 修复安装器逻辑、「还原原始文件」功能、dgVoodoo2 适配、双exe游戏识别等多项bug
- 核心组件升级：DLSS 运行库更新至 310.9.1（搭载第二代光线重建模型）、DLSS5-Feeder 更新至1.17.0、RenoDX 更新至6.5.3
- 新增第二套 OptiScaler 版本可选（pre-SR multipass 分支），不同游戏适配性更好
- 新增安全图形模式，解决窗口闪烁、画面残留问题
- 从 v2.2.8 版本开始不再限制 NVIDIA 驱动版本，无需降级驱动即可使用

> 版本选择建议：追求稳定选2.2.7；想体验新功能、新组件，或遇到2.2.7兼容性问题选2.2.9

### 2.3 安装步骤
1. 下载安装包（安装版或便携版均可），Windows 10/11 64位系统专用
2. 打开工具，支持自动扫描 Steam/Epic/GOG/Game Pass 游戏库，也可手动拖拽游戏文件夹添加
3. 选中目标游戏，选择安装方案：
   - **OptiScaler DLSS-NR**：适合**原生支持DLSS的64位游戏**，和上面的一键安装器核心方案一致
   - **Feeder 方案**：适合**无原生DLSS支持的游戏/模拟器**，通过中转层注入DLSS 5
4. 选择渲染API（默认推荐即可），点击「安装DLSS 5」，等待活动日志提示完成
5. 启动游戏，先在游戏画面设置里开启对应超分选项（DLSS/FSR/XeSS）即可生效

### 2.4 使用方法&快捷键
1. **游戏内面板**：默认按 `F8` 呼出/关闭设置面板，可在设置里自定义快捷键，支持 Ctrl/Alt/Shift 组合键
   - 面板开启时游戏会暂停，方便固定画面对比参数效果
   - 可直接调节神经渲染强度、结构、色调、帧生成档位等所有参数，实时生效
2. **帧率显示**：按对应快捷键可开启左上角帧率、延迟信息显示
3. **Multipass 方案**：若使用该方案，默认按 `Home` 键呼出专属面板

### 2.5 卸载还原
在工具内选中已安装的游戏 → 点击「Restore originals（还原原始文件）」，即可完全恢复游戏原始状态，卸载工具本身不会触碰任何游戏文件

## 通用常见问题
1. **开DLSS后画面闪烁**：尝试切换为XeSS/FSR 2超分方案，或在设置里开启安全图形模式
2. **应用设置后卡住**：属于正常加载，稍等几秒即可
3. **帧生成不生效**：确认游戏内已经开启对应超分选项，保存设置后重启游戏
4. **反作弊提示/封号风险**：工具属于修改游戏渲染文件，**多人联机、带反作弊的游戏慎用**，仅建议单机离线模式使用
5. **面板呼不出**：尝试切换快捷键组合，或检查是否和其他插件（如ReShade）快捷键冲突
